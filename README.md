# Ad-Tech Case Study

Data analysis case study on ad-tech click prediction using machine learning techniques.

## Overview

This project focuses on analyzing ad-click data to build predictive models for click-through rate (CTR) optimization.

## Contents

- `Ad_Tech.ipynb` - Complete case study notebook with:
  - Data exploration and understanding
  - Feature engineering
  - Predictive modeling
  - Analysis and insights

## Technologies Used

- Python
- Pandas & NumPy
- Machine Learning
- Data Visualization

## Getting Started

Open the Jupyter notebook to explore the complete analysis:

```bash
jupyter notebook Ad_Tech.ipynb
```
